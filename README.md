# Money Transfer & Agent Management System (Laravel Web App)

## Project Overview
This project is a Laravel-based money transfer system that enables users to send and receive funds through authorized agents. The system includes role-based access for Admin, Agent, and Client, and provides transaction monitoring, user management, and operational control through a secure web interface.

## Features

### Client
- Send and receive money
- View transaction history
- Secure login system
- Wallet balance tracking

### Agent
- Process deposits and withdrawals
- Confirm money transfers
- Manage client accounts
- View operational logs

### Admin
- Full system dashboard
- Manage agents and clients
- Monitor all transactions
- System configuration and control

## Technology Stack
- Backend: Laravel (PHP Framework)
- Frontend: Blade Templates
- Architecture: MVC
- Database: MySQL
- Authentication: Laravel Auth
- Roles: Admin, Agent, Client

## Security
- Input validation
- Role-based access control
- Secure authentication
- Transaction integrity checks

Project is under development and open for improvement.
